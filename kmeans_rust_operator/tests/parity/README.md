# Parity fixtures

Generated by the **R reference**: `stats::kmeans` as shipped in **R 4.3.3**
(Hartigan–Wong via `src/library/stats/src/kmns.f`), through the exact calls
the R operator makes — `set.seed(seed)` then `kmeans(mat, centers, iter.max,
nstart)`. Regenerate with:

```bash
cd kmeans_rust_operator
Rscript tests/parity/generate_goldens.R
```

The inputs are public or synthetic only:

| file | what it is |
|---|---|
| `test1_matrix.csv` | the R operator's own `tests/test1_in.csv`, projected the way `main.R` projects it (`acast(.ci ~ .ri, mean)`) |
| `iris_matrix.csv` | Fisher's iris, measurements only (150 × 4) |
| `synthetic_matrix.csv` | `set.seed(1); rnorm`, 300 × 8, 5 well-separated groups |
| `duplicates_matrix.csv` | seeded resample with replacement of a synthetic 120 × 5 matrix, so rows repeat — exercises the R wrapper's `unique(x)` re-sampling of duplicated initial centres |

Per case `<name>_k<k>_i<iter>_s<nstart>_seed<seed>`:

- `*_labels.csv` — R's `km$cluster` (1-based)
- `*_centers.csv` — R's `km$centers`, `%.17g` (round-trips a double exactly)
- `*_meta.csv` — `iter`, `ifault`, `tot.withinss` and per-cluster `withinss`, `%.17g`

`sample_int.csv` records raw `sample.int(m, k)` draws after `set.seed(seed)`
— the RNG stream the initial centres come from, checked draw for draw.

The cases cover: the operator's own golden parameters (test1, k=2, seed=42),
an `iter.max`-exceeded fit (`iris_k8_i1_s1_seed1`, `ifault` 2 — the port must
warn and return the same partial result), `nstart > 1`, and duplicated
initial centres. `ifault` 4 (quick-transfer step limit) exists in the port
but is not in the fixtures: it needs a pathological fit to trigger, and the
code path is a direct transliteration of R's.

All numeric fixtures are written with `sprintf("%.17g")`; 15 digits is not
enough to decide bitwise parity.
